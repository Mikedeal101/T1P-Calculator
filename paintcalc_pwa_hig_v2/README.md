
# Paint Price Calculator – HIG‑Refined UI

This version tweaks the layout to follow Apple’s Human Interface Guidelines:

* Uses **SF Pro** system font (`-apple-system`).
* 16 px base spacing, 12 px corner radius.
* High‑contrast `#007aff` system blue for the primary button.
* Inputs mimic iOS “filled” text fields, with focus ring.
* Dark‑mode adaptive colors (`prefers-color-scheme`).
* Tap target ≥44 px tall.
* Result displayed in a subtle card for visual hierarchy.

Deploy exactly like earlier (GitHub Pages, Netlify, etc.).
